# MicMute

Сборки пока не имеют цифровой подписи. Windows может показать предупреждение для нового скачанного приложения. Контрольные суммы SHA-256 позволяют проверить, что файл совпадает с опубликованным релизом.

Небольшая программа для Windows: переключает mute микрофона горячей клавишей, из трея или через экранный индикатор. C# 5, WinForms, .NET Framework 4.8, без NuGet-зависимостей.

## Установка

Нужны **Windows 10 или новее** и **.NET Framework 4.8 или новее**.

- **Установщик:** запустите `MicMute-Setup.exe`. Установка только для текущего пользователя, права администратора не нужны. Ярлык на рабочем столе и запуск при входе в Windows — необязательные пункты, изначально выключены.
- **Portable:** распакуйте `MicMute-portable.zip` в папку с правом записи и запустите `MicMute2.exe`. Не запускайте программу прямо из архива.

При первом ручном запуске откроются настройки. Язык по умолчанию — английский. Русский, испанский и шуточный вариант **Українська (суржик)** можно выбрать в **General → Language** (в русском интерфейсе — **Основное → Язык**). Настройки сохраняются в `MicMuteConfig.txt` рядом с EXE, резервная копия атомарного сохранения имеет суффикс `.bak`. Не публикуйте эти файлы: там могут быть идентификаторы устройств и локальные пути. Удаление программы сохраняет созданные пользователем настройки и собственные файлы. Пользовательские картинки и звуки лучше хранить отдельно, например в `assets/custom`: содержимым `assets/default` управляет установщик.

**Автозапуск:** включите или снимите галочку **Основное → Запускать при входе в Windows** и нажмите **ОК**. Программа и установщик используют один ярлык текущего пользователя. При входе MicMute не открывает настройки, не предупреждает о второй копии и не меняет mute. Индикатор отображается, если включён в настройках. Если галочка недоступна из-за другой копии, управляйте автозапуском из неё. Если Windows сама отключила приложение, проверьте **Параметры → Приложения → Автозагрузка**.

**Обновления:** при запуске MicMute один раз в фоне проверяет [GitHub Releases](https://github.com/kalderbabasina/MicMute/releases). Проверку можно отключить в **Основное** или запустить вручную через меню в трее. Для установленной версии загрузка и запуск Setup требуют подтверждения; перед запуском проверяется SHA-256. Устанавливайте обновление в ту же папку. Для portable откройте релиз, закройте MicMute и распакуйте новый ZIP поверх старой папки. Настройки в ZIP не входят.

## Управление

- В настройках выберите **микрофон Windows по умолчанию для связи** или конкретное активное устройство записи. Первый вариант следует за изменением устройства связи в Windows; второй закреплён за выбранным устройством.
- Mute переключается горячей клавишей, через значок трея или индикатор. По умолчанию используется **F13**. В настройках можно выбрать другую клавишу и модификаторы Ctrl/Alt/Shift. Комбинация, занятая другой программой, недоступна.
- Правый клик по значку трея открывает меню и настройки. Индикатор можно скрывать, показывать и блокировать.
- Перетаскивайте индикатор для перемещения, а с зажатым **Shift** — для изменения размера от **40 до 256 px**. Непрозрачность в настройках регулируется от **25 до 100%**. Блокировка запрещает перемещение и изменение размера, но оставляет переключение mute кликом.
- Серый **?** означает, что устройство недоступно или его состояние не удалось прочитать. Это **не** подтверждение mute. Проверьте подключение, разрешение на микрофон в Windows и выбор устройства.

Программа изменяет системный mute устройства, а не отдельную кнопку mute в Discord, игре или другом приложении. Другие программы и Windows тоже могут менять системный mute; индикатор показывает полученное состояние.

## Свои картинки и звуки

Для значков и индикатора есть три стиля: **Classic, Outline, Pixel**. Рядом с каждой строкой показан выбранный значок, а кнопка **Встроенный** возвращает стиль. В **Звуки → Источники звука** отдельно выберите для мута и анмута сигнал Windows, свой WAV/MP3, тишину или звук выбранного стиля. Кнопки предпрослушивания не переключают микрофон.

Встроенные варианты можно переопределить отдельно для включённого и заглушённого микрофона:

| Назначение | Форматы |
| --- | --- |
| Значки трея | `.ico` |
| Картинки индикатора | `.png`, `.bmp`, `.jpg`, `.jpeg`, `.ico` |
| Звуки переключения | `.wav`, `.mp3` |

Для индикатора удобно использовать изображения с прозрачностью. Каждый медиафайл ограничен 16 МБ, растровые изображения — 4096 пикселями по каждой стороне. Если собственный файл не удалось использовать, сработает выбранный стиль. Системный стиль использует звук Hand при выключении и Asterisk при включении микрофона; звучание зависит от схемы Windows. Локальные MP3 воспроизводятся через Windows MCI, который закрывает устройство воспроизведения по окончании трека. Дополнительных пакетов и кодеков в поставке нет. Личные медиа не попадают в публичные пакеты сборки.

## Приватность и ограничения

MicMute **не записывает звук** и не собирает телеметрию. Проверка обновлений обращается к публичным релизам GitHub и указывает версию MicMute в заголовке запроса; данные микрофона, настройки и пути к файлам не отправляются. Не публикуйте свой конфиг и резервные копии.

Индикатор — обычное окно «поверх остальных». Его видимость нельзя гарантировать в эксклюзивном полноэкранном режиме, на защищённом рабочем столе UAC и поверх защищённых окон. Горячие клавиши могут перехватываться или ограничиваться другим ПО. Программа не заменяет аппаратное отключение микрофона и не является средством защиты от записи.

## Сборка

Нужны Windows PowerShell **5.1** и .NET Framework **4.8**. Используется встроенный компилятор Framework `csc.exe`; .NET SDK и Visual Studio не обязательны.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test
```

Для установщика дополнительно нужен **Inno Setup 6 или 7**. Английский текст доступен всегда; русский и испанский включаются, если соответствующие переводы есть в установленном компиляторе:

```powershell
.\build.ps1 -Test -Installer
.\build.ps1 -Installer -InnoCompiler "C:\Tools\Inno Setup 6\ISCC.exe"
```

Результаты: `dist/portable/MicMute2.exe`, `dist/MicMute-portable.zip`, а с параметром `-Installer` — `dist/installer/MicMute-Setup.exe`. ZIP создаётся из отдельной временной папки по белому списку: только EXE, стандартные значки, лицензия, README и уведомления об авторстве. Старый `dist` рекурсивно не удаляется, локальные настройки не очищаются. Для MSBuild/Visual Studio также есть классический `MicMute.csproj`; ему нужен targeting pack .NET Framework 4.8.

GitHub Actions только собирает, запускает smoke-тесты и сохраняет артефакты. Публикации релизов и deploy нет. Smoke-тесты не заменяют ручную проверку микрофона, горячих клавиш, индикатора, смены устройства и установки в Windows.
